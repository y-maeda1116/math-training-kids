# さんすうトレーニング 🔢

小学生向けの1桁（ひとけた）けいさんれんしゅうアプリ。
たしざん・ひきざん・かけざん・わりざんを、ゲーム感覚で楽しくトレーニングできます。

🔗 **[https://y-maeda1116.github.io/math-training-kids/](https://y-maeda1116.github.io/math-training-kids/)**

## 遊びかた

ホーム画面で3つを選んで「スタート！」を押します。

1. **たんごをえらぶ** — たしざん / ひきざん / かけざん / わりざん / ★ミックス
2. **ほうしきをえらぶ** — ⏱ 10問タイムアタック / 🔁 エンドレス
3. **こたえかたをえらぶ** — 🔤 4択 / 🧮 じかにいれる

### ほうしき

| ほうしき | 内容 |
|---|---|
| ⏱ 10問タイムアタック | 10問のタイムと正解数を計測。ランク判定（⚡ゴールド / 🌟シルバー / 💪ブロンズ） |
| 🔁 エンドレス | まちがえるまでつづく。5れんぞくごとにおいわい演出 |

### こたえかた

- 🔤 **4択** — 正解と、まちがえやすいダミー3つのボタンからえらぶ
- 🧮 **じかにいれる** — 電卓風テンキーで答えを入力。暗記・自力想起の練習に（2桁まで入力可）

## 出題ルール

| たんご | ルール |
|---|---|
| たしざん | 1桁 + 1桁 |
| ひきざん | 1桁 − 1桁（こたえはマイナスにならない） |
| かけざん | 九九（1桁 × 1桁） |
| わりざん | わる数は1桁・わりきれる問題のみ（あまりなし） |

## 技術

- **単一HTMLファイル**（`index.html`）— HTML / CSS / JavaScript、依存ライブラリなし
- フォント: [M PLUS Rounded 1c](https://fonts.google.com/specimen/M+PLUS+Rounded+1c)（Google Fonts）
- ホスティング: GitHub Pages（`main` ブランチへの push で自動デプロイ）
- 対応: モバイル / PC のレスポンシブ、`prefers-reduced-motion` 対応
